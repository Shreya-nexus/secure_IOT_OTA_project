🔒 System Security Features

Cybersecurity Matrix
✓

Device Authentication

SHA-256 token hashing for registered ESP32 nodes.

✓

Admin Authorization

Strict administrative checks on binary upload endpoints.

✓

Firmware .bin Validation

Strict MIME type and binary extension enforcement.

✓

SHA-256 Hash Integrity

Automatic server-side SHA-256 checksum generation.

✓

Path Traversal Protection

Sanitization via Werkzeug and strict directory bounds.

✓

Update Audit Logging

Immutable event logging for success and failure attempts.

⚠️ Cybersecurity Distinction Note: SHA-256 provides firmware integrity checking (preventing corruption). It does not by itself prove firmware authenticity (which requires asymmetric digital signatures like ECDSA/RSA).
